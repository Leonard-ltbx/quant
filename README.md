# 量化

公开的量化研究仪表盘。行情数据来自腾讯财经公开行情接口，由 GitHub Actions
在交易日每 15 分钟更新一次。网页中的“规则评分”使用实时涨跌幅、量比、换手率、
PE、PB，以及历史动量、均线与波动率等公开字段计算，不是 AI 预测，也不构成投资建议。

真实回测采用“20 日动量轮动”示例策略：每 20 个交易日，依据当时可见的过去
20 日收益率，在 6 只自选股中等权持有前 2 只，并计入 0.03% 换仓成本。页面同时
展示沪深 300 同期收益。回测只用于验证规则，不代表未来收益。

数据更新脚本：`scripts/update_market.py`

自动更新流程：`.github/workflows/update-market.yml`
